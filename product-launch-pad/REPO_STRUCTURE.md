# Repository structure

This repo is a Vite + React product launch pad.

```text
product-launch-pad/
├── README.md
├── AGENTS.md
├── .gitignore
├── .prettierignore
├── .prettierrc
├── package.json
├── bun.lock
├── bunfig.toml
├── components.json
├── eslint.config.js
├── tsconfig.json
├── vite.config.ts
├── .lovable/
├── public/
├── src/
└── ...
```

## Notes

- `src/` contains application code.
- `public/` holds static assets.
- `components.json` and Vite config define the frontend tooling.
